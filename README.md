# NovaCart — Responsive E-commerce Frontend

A responsive demo storefront built with **HTML, CSS and vanilla JavaScript**.

## Features
- Responsive layout for desktop, tablet and mobile
- Product cards, category filters, search and sorting
- Add to cart, remove items and change quantities
- Cart subtotal and item count
- Cart saved in browser `localStorage`
- Wishlist toggles (session-only)
- Product quick-view modal with quantity picker
- Light/dark theme toggle saved in localStorage
- Animated product cards and polished modal interactions
- Newsletter form demo and toast notifications
- Accessible labels and reduced-motion support

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser, or use the VS Code **Live Server** extension.
3. Internet is required for the Google Font and remote product photos.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important
This is a frontend demo. It does **not** include a real database, user authentication, order management, or payment processing. The checkout button only shows a demo message. For a real store, connect a backend and a trusted payment provider.
